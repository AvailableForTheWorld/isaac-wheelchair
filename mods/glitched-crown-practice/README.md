# 错误王冠：无尽模式

![错误王冠与正确勾标记封面](assets/workshop-cover.png)

错误王冠（Glitched Crown，也常称为混乱王冠）的单房间五选一时机练习。启用后，**新开局直接进入「无尽模式」**：根据目标提示接触道具底座，每次选择结束后自动继续下一轮。没有 120 次或其他轮数上限，也没有探索地下室的流程。

## 使用

1. 关闭游戏，运行下面的安装命令。
2. 在游戏的 Mods 菜单启用「错误王冠：无尽模式 / Glitched Crown Endless Practice」。
3. 关闭参考模组 `szx_gcrown_challenge_3433101828`，以及改变开局、角色、房间、道具池或道具轮换行为的其他模组，避免练习流程相互干扰。
4. 开始一个新的单人普通游戏。观察 HUD 右上方的目标图标、名称和道具 ID，以及底部的当前移速，移动角色拾取正在轮换的道具。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -Mod glitched-crown-practice
```

此命令从仓库根目录运行，将独立包安装到游戏的 `mods/glitched-crown-practice` 目录。退出后选择 **Continue / 继续游戏**，会保留同一局种子的累计统计；开始新的一局会清零。请使用新开局进入练习，避免用已有的正常游戏存档试用。恢复常规游戏前，在 Mods 菜单禁用本模组。

## 统计与偏差

HUD 显示已选择次数、正确次数、错误次数、成功率，以及四条独立的偏差统计：

| 字段 | 含义 |
| --- | --- |
| `-1 次数` | 拾取到了轮换顺序中目标道具的**前一个** |
| `+1 次数` | 拾取到了轮换顺序中目标道具的**后一个** |
| `-2 次数` | 拾取到了轮换顺序中目标道具的**前两个**位置上的道具 |
| `+2 次数` | 拾取到了轮换顺序中目标道具的**后两个**位置上的道具 |

上一轮结果还会显示本次偏差。命中时显示「选中目标」（偏差为 `0`）；每次错误只增加对应的一条偏差统计，同时增加错误总数。

从 1.0.0 升级后，原来的总次数、正确次数、`-1`、`+1` 统计会保留。旧版本无法区分历史 `-2` 和 `+2` 的方向，因此这部分保留并显示为「历史未分类」错误；新增加的 `-2`、`+2` 次数从零开始，不会推测或重分已有错误。新开局会重置全部统计。

方向按本轮底座**实际显示的循环顺序**计算。假设它按 `A → B → C → D → E → A` 轮换，目标为 `A`：选到 `E` 是 `-1`，选到 `B` 是 `+1`，选到 `D` 是 `-2`，选到 `C` 是 `+2`。这里描述的是选中的道具相对目标的位置，不是估算按键提前或延迟了几帧。

使用游戏原生错误王冠轮换及拾取判定，不人为放慢或自行模拟五选一道具。每轮先识别五件不同道具及其顺序，再开放选择；识别过程中不能计分。外部效果改变道具时，该轮会重新准备，避免把不完整的顺序误记为偏差。目标图标使用游戏自身道具资源，同时显示名称和道具 ID。模组内置训练池 51 件道具的中英文名称，不依赖额外中文道具翻译模组。

为了固定练习条件，角色会统一为以撒，每轮清空已有道具、饰品和上一轮的变身进度，再给予原生错误王冠。训练池包含 51 种不会在拾取时传送或重置房间的被动道具，每轮随机抽取五件不同道具。保留移动与游戏暂停，禁用射击、炸弹、主动道具和卡牌，封闭房间出口；不会累积已选道具的效果。每次结果停留约 1.5 秒后自动开始下一轮，底部保留最近结果。

## 每轮移速

每个新练习回合都会抽取一个移速，范围为 **0.7–2.0**。抽样使用均值 **1.35**、标准差 **0.22** 的正态分布；超出范围的数值会重新抽取，形成截断正态分布，不会直接夹到上下限。大多数回合接近中间移速，极慢或极快的回合较少。

HUD 的「当前移速」显示角色当前实际的移动速度属性，保留两位小数。该值在本轮中保持稳定；无效回合重试或尚未完成选择时退出后 Continue 会保留同一移速，完成选择并开始下一轮时才重新抽取。如果在结果展示期间退出，Continue 会开始下一轮并抽取新移速。随机的是角色移速，错误王冠的原生轮换速度保持不变。

## 兼容与验证

- 目标环境为《以撒的结合：忏悔+》（Repentance+）。
- 面向单人训练。多人联机、每日挑战和其他挑战流程不在此练习模组的支持范围内。
- 不依赖参考模组、EID、Mod Config Menu 或其他模组的字体及文件。
- 本仓库的静态检查、模拟测试和本地安装不能代替游戏内验证。首次启动请检查中文道具名称、当前移速、四种方向偏差、超过 120 次后的继续练习，以及退出后 Continue 的统计和移速恢复。

从仓库根目录用 Lua 5.3+ 运行回归检查：

```text
lua tests/glitched-crown-practice_spec.lua
```

检查包含循环边界、连续 10,000 次选择、计数一致性、实际拾取队列优先于底座消失、暂停、重试，以及退出和继续游戏的统计恢复。

## 文件与资源

`content/` 是完整的游戏运行及 Workshop 发布包。模组仍为本地版本，尚无 Workshop ID。参考模组仅用于理解单房间练习体验，没有复制其字体贴图或依赖其安装路径。

中文 HUD 使用本模组生成的点阵贴图 `resources/font/gcpractice.png` 和二进制 BMFont v3 描述 `gcpractice.fnt`。中文以 Windows 本机安装的 **SimSun（宋体，`C:/Windows/Fonts/simsun.ttc`）** 生成，英文和数字使用 **Microsoft YaHei（微软雅黑，`C:/Windows/Fonts/msyh.ttc`）**，基线对齐。两者均在最终 **13 px** 字号直接进行单色像素栅格化，按原始尺寸、整数坐标绘制，避免缩小抗锯齿贴图产生模糊。统计行距为 17 px，目标区域只显示道具图标，并在下方紧凑排列名称和较淡的道具 ID。

贴图包含中文标签、训练池道具名称及可打印 ASCII；包内不包含源 TTF/TTC 字体。生成器自动扫描 `content/` 下的 Lua 中文文本，避免新增道具名称后漏掉字形。完整字集见 [`assets/font-glyphs.txt`](assets/font-glyphs.txt)。

道具名称表位于 `content/scripts/items.lua`，只收录本模组训练池的 51 件道具。ID 对照本机游戏的 `CollectibleType` 枚举，名称对照已安装 EID 的中英文名称表核验；运行时不读取 EID 文件，也不包含它的完整翻译目录。

生成脚本位于 [`assets/generate_font.py`](assets/generate_font.py)，不随游戏包安装。安装 Pillow 后可以重建，也可以用 `--font`、`--ascii-font` 指定本机其他支持这些字形的字体：

```powershell
python .\mods\glitched-crown-practice\assets\generate_font.py
```

[`assets/check_font.py`](assets/check_font.py) 会核对运行代码与 51 件道具名称的中文文本是否都有对应字形，并按 HUD 的 480 × 270 布局生成预览，覆盖最长中文目标名、四种偏差次数、历史未分类错误和当前移速。该预览用于检查字形和排版，不是游戏截图，也不能验证游戏的字体加载行为。
