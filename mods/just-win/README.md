# 假如我直接赢

![「just win」封面，点赞角色下方是紫色 3 级与金色 4 级徽标](assets/workshop-cover.jpg)

《以撒的结合：忏悔+》（Repentance+）模组。房间里品质不足 3 级的普通道具会替换成随机的 3 或 4 级道具。进房、回房、读档、重掷和房间内新生成的底座都适用。

- **任务道具**保留原样，包括底片、全家福、两块刀片碎片和两块钥匙碎片。
- **未解锁候选**在可用的 3、4 级道具少于候选总数三分之二时加入替换抽取，抽中概率按未解锁候选比例计算。其余替换优先从原道具池或当前房间的池子抽取。用完可用的未重复候选后，直接从余下未解锁的 3、4 级道具补位。模组只影响当局道具生成，解锁进度照常记录。
- **变身套装**按可出现的道具品质从高到低补足三件。第三高品质并列的道具都能保留。例如猫套会保留 2 级的猫眼、猫尾和猫头。超级乞丐、踩踏和死灵法师所需的特定道具也可照常出现。
- **轮换底座**使用游戏原生轮换。筛选普通选项时会排除本房间已经抽出的道具，包括错误王冠同一底座的其他选项。大胃王额外提供的食物仍可选，品质可以低于 3 级。
- **死亡证明**保留原生目录中的各件固定陈列，让玩家按道具本身选择。
- **定向重掷和复制**保留计数骰、复眼和弯硬币实际生成的道具。已经出现或拿过的道具可以通过这些效果再次获得，低品质的定向结果和复制品也可照常拾取。计数骰的目标沿用原版解锁条件，错误王冠由这些效果额外抽取的随机槽位继续筛选和去重。
- **拾取后移出道具池**。道具进入背包后，从原版随机道具池和模组的随机替换候选移除。合作玩家共用记录，跨楼层与继续游戏时保留，开新局时清空。高品质候选用完后沿用游戏的道具池耗尽行为。
- 底座替换保留价格和多选组。规则适用于可拾取的道具底座。

## 安装

关闭游戏后，在仓库根目录运行以下命令。启动游戏后，在 Mods 菜单启用「假如我直接赢」。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Mod.ps1 -Mod just-win
```

如果本机通过创意工坊安装了本模组，可加 `-WorkshopCopy` 更新已有的订阅副本。

## 验证

从仓库根目录运行 `lua tests/just-win_spec.lua`，用 Lua 5.3+ 检查品质筛选、任务保护、同房间去重、定向重掷与复制、死亡证明目录和拾取后的道具池移除。游戏内可以持有错误王冠后用计数骰或复眼测试底座，检查定向结果和额外的随机槽位。
